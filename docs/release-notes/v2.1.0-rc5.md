# TactiQ OS v2.1.0-rc5

**Release candidate — not a GA release.** This image is published for
qualification and review. The CVE posture below is raw scanner output under
honest disclosure; driving it to zero is a GA gate, not an rc5 gate.

Built from a complete Yocto *wrynose* build (`20260622045650`); verified
booting on Radxa Rock 5A (RK3588S).

## Changes since rc4

First release on the wrynose toolchain. The migration touched the full stack:

- **Yocto:** scarthgap → wrynose (6.0)
- **Kernel:** 6.6 → 6.18 (`6.18.24+git`)
- **SBOM:** SPDX 2.2 (per-recipe `.spdx.tar.zst` aggregate) → SPDX 3.0.1
  (single self-contained image document)
- **CVE tooling:** `cve-check` (removed in wrynose) → `sbom-cve-check`
- **Release tooling:** `build-rc-artifacts.sh` + `spdx-aggregate.py` →
  `mk-release.sh` (single-build consistency guard) with embedded
  `enrich-cve.sh` kernel-CVE enrichment
- **Artifact naming:** new scheme (see Artifacts); old names (`rootfs.ext4`,
  `*.spdx.tar.zst`, `cve-full`) retired

### Image composition
- `python3` dropped from the production image (#43)
- excluded: `jq`, `shared-mime-info`, `libxml2`

> Verify this line against `manifest-rock5a.txt` before tagging.

## Security posture

- **SELinux** enforcing; LSM stack `lockdown,capability,selinux,integrity`;
  IMA enabled (measurements to PCR 10).
- **CVE posture: 35** image-scoped entries (CVSS v3 base ≥ 7.0, status
  Unpatched). Scoring is **v3-only** for rc5; v4 is deferred to GA. Full
  triage in `SUPPLY_CHAIN.md`.
  - 11 confirmed version-in-range (glibc ×5 incl. the 9.8 `CVE-2026-5450`,
    curl ×2, expat ×2, systemd ×1, kernel ×1)
  - 24 without version ranges: 20 kernel (per-CVE "fixed in 6.18?" triage is a
    GA item — these are **not** bulk-resolved), 4 SELinux `CVE-2016-7545`
    (not-applicable: `seunshare` not shipped; VEX pending)

## Hardware

Verified booting on Radxa Rock 5A (RK3588S). This image runs the CPU
inference path; NPU enablement and latency qualification are tracked
separately and are **not** part of rc5.

## Deferred / known limitations

- **RAUC / OTA:** no `.raucb` bundle in rc5. The A/B partition layout is
  present; the OTA update path is not exercised in this candidate.
- **buildinfo:** `buildinfo-rock5a.json` is omitted from rc5 and deferred to GA.
- **Reproducibility:** the two BSP sources (`u-boot-rockchip` kwiboo fork,
  `rkbin`) are sha256-pinned but require re-fetch to rebuild; wrynose
  reproducibility re-measurement is pending.
